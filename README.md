# CES Test 2026 - Practice Question Data

Original practice questions with answers and explanations, used by the
"CES Test Answers 2026" iOS app. These are independent study questions written
for practice. They are not real or leaked test items.

Not affiliated with Seagull or Ocean Technologies Group.

Layout:
- `data/manifest.json` - version, updatedAt, departments -> categories (count, file)
- `data/<department>/<category>.json` - array of questions
